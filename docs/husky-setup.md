# Husky Setup

## Ferramentas

- **Husky**: Git hooks
- **Lint-Staged**: Lint apenas arquivos staged
- **Commitlint**: Valida Conventional Commits

## Fluxo

1. `pre-commit`: ESLint + Prettier
2. `commit-msg`: Valida mensagem

## Commits

`feat(auth): add login`

Tipos: `feat`, `fix`, `docs`, `chore`, `style`, `refactor`, `test`
